# Matilda Garay

Carpeta para visualizar resúmenes del proyecto con Streamlit.

## Ejecutar

Desde la raíz del proyecto:

```bash
streamlit run Notebooks/Matilda\ Garay/app.py
```

## Contenido

- Resumen general del proyecto
- Gráficos por estado y tipo de proyecto
- Tabla con los proyectos de mayor monto
